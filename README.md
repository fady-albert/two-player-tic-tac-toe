# Tic-Tac-Toe

A modern Tic-Tac-Toe game built with **HTML**, **CSS**, and **JavaScript**. It features multiple game modes, AI opponents with different difficulty levels, score tracking, sound effects, dark mode, and a clean responsive interface.

## Live Demo

**Play Now:** https://fady-albert.github.io/TIC-TAC-TOE/

---

## Features

- Two game modes
  - Normal Mode
  - Limited Mode (Each player can only have 3 marks on the board)

- Multiple play options
  - 2 Players
  - Play against AI

- Three AI difficulty levels
  - Easy
  - Medium
  - Hard

- Dark Mode support

- Sound effects

- Scoreboard

- Game reset

- Reset scores

- Responsive modern UI

- Fast and lightweight (No frameworks)

## Built With

- HTML5
- CSS3

## Game Modes

### Normal Mode

Players place their marks until one player gets three in a row.

### Limited Mode

Each player can only have **3 marks** on the board.

Once all three marks are placed, players must **move one of their existing marks** instead of placing a new one.

This creates a more strategic version of the classic Tic-Tac-Toe.

---

## AI Difficulty

### Easy

- Chooses random valid moves.

### Medium

- Mixes smart moves with random decisions.
- Can miss winning opportunities.

### Hard

- Uses the **Minimax Algorithm** to choose the optimal move.
- Provides the most challenging AI opponent.

---

## How to Play

1. Choose a game mode.
2. Choose your opponent.
3. If playing against AI, choose the difficulty.
4. Take turns placing your marks.
5. In Limited Mode, move one of your existing marks after placing three.
6. Get three marks in a row to win.
7. Track your score and play again.
